# skills/ — 中央 Skill 工厂的下发目录

此目录对齐 Claude Agent SDK 的技能加载约定(运行时把中央 registry 的 Skill 包同步到此处,
SDK 自动按 agentskills.io 开放标准渐进式加载:元数据 → 全文 → 捆绑文件)。

## M1 约定

- M1 网关尚未接入 Agent 运行时(Echo 回声),此目录先占位并固定布局;
- `demo-answer/` 是一个最小可读的 SKILL.md 样例,展示 frontmatter 格式;
- M2 起:中央 registry(git/对象存储)→ 版本 → 按部门灰度同步到每个 worker 的 skills 目录。

## Skill 分类法(调研报告 §3,L3 层)

| 类型 | 内容 | 示例 |
|---|---|---|
| 知识型 | SOP、产品手册、故障树、价格政策 | 冷柜 E4 报警排查树 |
| 流程型 | 多步骤作业指导,带检查点和确认门 | 新品陈列 12 步验收流程 |
| 工具型 | 捆绑脚本做确定性计算/读取 | 耗材用量计算器 |
| 合规型 | 行业检查清单、话术红线、上报规则 | 金融适当性话术红线 |

## 红线(架构期定死,调研报告 §四)

- Skill 只从中央 registry 分发,不接受终端上传;
- 入库必过代码审计 + 依赖扫描 + 网络出口白名单;
- 生产环境禁用 Bash 与文件写工具,业务工具走白名单 MCP。
